# Voter Ready - Assignment 7

## Project Overview

Voter Ready is an educational website designed to help young adults and first-time voters understand the voting process. The website includes information about registration, voting methods, elections, and frequently asked questions.

I also created an interactive Election Challenge game where visitors can help different characters understand voting situations.

[Visit Voter Ready](https://oliviaellegaard-design.github.io/WebDesign/Assignment7/)

## Project Reflection

### 1. What is one HTML, CSS, or publishing skill you feel stronger in now?

One skill I feel stronger in is using HTML, CSS, and JavaScript to create interactive features on my website. Throughout this project, I learned how to organize my code, use Flexbox and Grid to create a more cohesive layout, and make different elements interactive. I also became more comfortable using the terminal and GitHub to publish changes. At first, updating my website was challenging, but after practicing and troubleshooting, I became more confident.

### 2. How did it feel to navigate your own site? Is there anything that could make it more intuitive or enjoyable?

Navigating my website felt simple and organized because I wanted users to easily find information without feeling overwhelmed. Since my website focuses on young adults and first-time voters, I separated information into different pages, such as registration, how to vote, elections, and FAQs.

I also added interactive features, including a state selection dropdown and different voting options, to make finding information more enjoyable. One improvement I could make is creating smoother transitions between pages and adding more visual elements to keep users engaged.

### 3. Where did you struggle during the project? How did you address it?

One of my biggest struggles was getting my interactive game to work properly and making sure my changes were published through GitHub. There were several times when the terminal said there was nothing to commit, even though I was trying to update my website.

I learned how to save HTML and JavaScript into the correct files and use PowerShell commands to publish changes. Through trial and error and troubleshooting, I became more confident in organizing my files and understanding how GitHub works.

### 4. If you had just one more week to work on this project, what would you add, change, or refine?

If I had one more week to work on my website, I would focus on finding more short-form educational content, especially videos that I could embed throughout my website.

Since my target audience is young adults and first-time voters, I believe shorter videos would make important voting information easier to understand and more engaging.

I would include videos that answer frequently asked questions, explain voting requirements, and provide helpful information for college students voting out of state. My goal would be to make the website more informative, accessible, and enjoyable for young adults.

### 5. What are you most proud of? Did anything surprise you?

The part of my website I am most proud of is my interactive Election Challenge game. I put a lot of thought and effort into creating something educational and fun for young adults.

I wanted to put myself in the shoes of a first-time voter and think about questions or concerns they might have.

By using emoji characters representing college students and other young adults, I created role-playing situations that help users understand voting information from different perspectives.

I also added a points system, progress bar, and feedback to make the game more engaging.

I was surprised by how much work goes into creating interactive features, especially using JavaScript. Although it was challenging, seeing my game finally work made me proud of how much I learned.
